# DTF XPERF — Téléchargements

Installateurs publics de DTF XPERF (logiciel protégé par licence).
Le code source reste privé ; ces fichiers sont des exécutables compilés.

## Liens de téléchargement

- **Lien fixe (toujours la dernière version)** :
  `DTF-XPERF-Setup-latest.exe`
- **Version précise** : `DTF-XPERF-Setup-1.1.0.exe`

Pour publier une nouvelle version : remplacer `DTF-XPERF-Setup-latest.exe`
par le nouvel installateur (et ajouter aussi la version numérotée).
